# 🔢 Simple Calculator App (Flutter)

This is a basic and clean **Calculator App** developed using **Flutter**. It performs fundamental arithmetic operations like addition, subtraction, multiplication, and division with a user-friendly interface.

## 🚀 Features

- Beautiful and responsive UI
- Supports basic operations: `+`, `-`, `×`, `/`
- Real-time calculation display
- Flutter clean design principles
